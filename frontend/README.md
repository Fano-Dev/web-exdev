# 🚧 Estado del proyecto

Actualmente estoy desarrollando un prototipo de mejora para la página web del club ExDev.

La plataforma está enfocada en la visualización de la historia, cultura, miembros y proyectos del club, además de integrar un formulario de postulación para nuevos integrantes.

Este prototipo busca modernizar la interfaz, mejorar la experiencia de usuario y optimizar la organización y acceso a la información.


# 🎯 Objetivos
- Mejorar la navegación y usabilidad del sitio
- Optimizar la presentación de contenido (historia, cultura y proyectos)
- Implementar y mejorar el sistema de postulación
- Evaluar nuevas funcionalidades para futuras versiones


# 🛠️ Tecnologías utilizadas
- HTML
- CSS
- JavaScript
- TypeScript (TSX)
